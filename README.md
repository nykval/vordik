# Вордик

Локальное приложение для личного словаря английских слов. В разделе «Учить» доступны флеш-карточки, выбор перевода и написание слова. Слова сохраняются в хранилище браузера **на том устройстве, где вы их добавили**. При очистке данных браузера они могут исчезнуть; синхронизации между устройствами пока нет.

Счётчик дней подряд увеличивается после первого запуска тренировки за день. Если пропустить целый день, серия прервётся. История занятий тоже хранится на устройстве.

## Запуск на компьютере

Откройте терминал в папке проекта и выполните:

```sh
node server.mjs
```

Затем откройте `http://localhost:4173` в браузере компьютера. Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Открыть на телефоне в домашней сети

Компьютер и телефон должны быть в одной сети Wi-Fi. При запуске сервер напечатает ссылку для телефона. Откройте её на телефоне, пока сервер работает. Данные телефона и компьютера будут храниться отдельно. При желании добавьте страницу на домашний экран через меню браузера.

## Открыть в Telegram

Файлы приложения находятся в корне репозитория: `index.html` открывается как главная страница GitHub Pages, а `README.md` остаётся инструкцией на GitHub. Опубликуйте изменения в ветке `main`; для GitHub Pages выберите источник **Deploy from a branch → main → /(root)**. Адрес приложения: `https://nykval.github.io/vordik/`. Именно этот адрес назначьте кнопке Web App или пункту меню бота через BotFather. Ссылка на `github.com/nykval/vordik` открывает страницу репозитория, а локальный `localhost` недоступен телефону через Telegram. Для общего словаря на нескольких устройствах в будущем понадобится серверное хранение данных.
