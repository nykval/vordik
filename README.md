# Вордик

Локальное приложение для личного словаря английских слов и повторения с карточками. Слова сохраняются в хранилище браузера **на том устройстве, где вы их добавили**. При очистке данных браузера они могут исчезнуть; синхронизации между устройствами пока нет.

## Запуск на компьютере

Откройте терминал в папке проекта и выполните:

```sh
node server.mjs
```

Затем откройте `http://localhost:4173` в браузере компьютера. Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Открыть на телефоне в домашней сети

Компьютер и телефон должны быть в одной сети Wi-Fi. При запуске сервер напечатает ссылку для телефона. Откройте её на телефоне, пока сервер работает. Данные телефона и компьютера будут храниться отдельно. При желании добавьте страницу на домашний экран через меню браузера.

## Подключить к Telegram позже

Приложение уже учитывает интерфейс Telegram Mini App. Для открытия из бота потребуется разместить содержимое `dist/` на доступном через **HTTPS** адресе и назначить этот URL кнопке Web App или пункту меню бота через BotFather. Обычный локальный адрес `localhost` Telegram на телефоне открыть не сможет. Для общего словаря на нескольких устройствах в будущем понадобится серверное хранение данных.
