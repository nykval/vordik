# Вордик

Приложение для личного словаря английских слов. В разделе «Учить» доступны флеш-карточки, выбор перевода и написание слова. Слова сохраняются в хранилище браузера **на том устройстве, где вы их добавили**. При очистке данных браузера они могут исчезнуть; синхронизации слов между устройствами пока нет.

Счётчик дней подряд увеличивается после первого запуска тренировки за день. Если пропустить целый день, серия прервётся. История занятий тоже хранится на устройстве.

## Рейтинг пользователей

Рабочий сервер рейтинга находится в `cloudflare/worker.mjs`, а общая таблица лидеров хранится в Cloudflare D1. Рейтинг рассчитывается по текущему уровню словаря: сложность каждого слова умножается на уровень знания от 1 до 10, делится на 10 и округляется, затем результаты складываются. В профиль выводятся место пользователя, его баллы и первые десять участников.

## Автоматическая озвучка новых слов

Генератор находится в `audio_generator.py` и использует британский женский голос `en-GB-SoniaNeural`. Новое пользовательское слово сначала сохраняется в словаре браузера, после чего интерфейс неблокирующим запросом вызывает `POST /api/audio/generate`. Локальный Node.js-сервер запускает генерацию в фоне; готовые MP3 сохраняются в `audio/`. Загруженные ранее дорожки общего словаря продолжают храниться в `audio/common/` и повторно не создаются.

Установите Python-зависимость:

```sh
python3 -m pip install -r requirements.txt
```

Создать одну дорожку вручную:

```sh
python3 audio_generator.py --word "to play"
```

Создать только отсутствующие дорожки общего словаря с тремя одновременными запросами:

```sh
python3 generate_missing_audio.py --concurrency 3
```

То же через npm:

```sh
npm run audio:missing
```

Настройки генератора:

- `VORDIK_AUDIO_DIR` — папка для MP3; по умолчанию `audio/` проекта.
- `VORDIK_PYTHON` — команда запуска Python; по умолчанию `python3`.
- `AUDIO_GENERATION_CONCURRENCY` — число одновременных генераций; по умолчанию 3.
- `AUDIO_PUBLIC_BASE_URL` — публичный адрес Node.js-сервиса, с которого браузер загружает созданные MP3.
- `AUDIO_SERVICE_SECRET` — общий секрет между Cloudflare Worker и Node.js-сервисом.

Cloudflare Worker не запускает Python самостоятельно. Для опубликованной версии разверните `server.mjs` на сервере с Node.js, Python и постоянным диском, затем задайте Worker-переменную `AUDIO_SERVICE_URL` с адресом этого сервера и одинаковый секрет `AUDIO_SERVICE_SECRET` на обеих сторонах. Worker будет проксировать `/api/audio/generate` и `/api/audio/status`, а MP3 будут отдаваться непосредственно аудиосервисом.

- В опубликованной версии рейтинг принимает только пользователей, подтверждённых Telegram Mini App.
- `BOT_TOKEN` хранится в Cloudflare Secrets и никогда не отправляется в браузер.
- Для локальной разработки можно включить гостевой режим. Устройство получает постоянный анонимный идентификатор в локальном хранилище браузера.

## Публикация в Cloudflare

1. Установите Wrangler и войдите в Cloudflare:

```sh
npm install
npx wrangler login
```

2. Создайте базу D1:

```sh
npx wrangler d1 create vordik-ratings
```

Скопируйте выданный `database_id` вместо `00000000-0000-0000-0000-000000000000` в `wrangler.jsonc`.

3. Создайте таблицу рейтинга:

```sh
npm run db:migrate:remote
```

4. Сохраните токен Telegram-бота как секрет:

```sh
npx wrangler secret put BOT_TOKEN
```

5. Опубликуйте приложение и API одним Worker:

```sh
npm run deploy
```

Wrangler вернёт HTTPS-адрес вида `https://vordik.<аккаунт>.workers.dev`. Его нужно назначить кнопке Web App или пункту меню бота через BotFather.

## Локальная проверка Cloudflare-версии

Скопируйте `.dev.vars.example` в `.dev.vars`, затем выполните:

```sh
npm run db:migrate:local
npm run dev
```

Wrangler поднимет локальный Worker со статическими файлами, API и локальной копией D1.

## Настройки Cloudflare

- `BOT_TOKEN` — токен Telegram-бота для проверки пользователя.
- `ALLOW_GUEST_RATINGS=true` — разрешить гостевой рейтинг; в опубликованной конфигурации выключено.
- `ALLOWED_ORIGINS=https://example.com` — разрешённые адреса отдельного фронтенда через запятую.

Автоматические проверки:

```sh
npm test
```

## Резервный локальный Node.js-сервер

Старый локальный сервер оставлен для разработки без Wrangler:

```sh
node server.mjs
```

Если интерфейс всё же остаётся на GitHub Pages, укажите адрес опубликованного Worker в метатеге `vordik-api-base` внутри `index.html`, а адрес GitHub Pages добавьте в `ALLOWED_ORIGINS` в `wrangler.jsonc`.
