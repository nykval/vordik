# Вордик · Система цветов

Основной цвет — насыщенный синий **#355CFF** вместо #4667D9. Палитра рассчитана на светлый интерфейс. Насыщенность сосредоточена в действиях и иллюстрациях; большие интерфейсные поверхности остаются светлыми.

Светлый — фон или освещённая плоскость, основной — главный объект, глубокий — тень или деталь. Тёмный фон допустим для ночных сцен. Белый #FFFFFF — для бликов и искр. В одной иллюстрации обычно достаточно двух цветовых семейств и небольшого акцента: не использовать все цвета сразу.

Для синей иллюстрации использовать триаду #BFCFFF / #355CFF / #2039B4. Иллюстрационные оттенки не являются автоматически подходящими цветами для мелкого текста.

## Правила применения

В интерфейсе синий отвечает за основные действия. На одном экране обычно достаточно одного или двух дополнительных акцентов; семантические цвета появляются по необходимости. Белый текст уверенно использовать на синем 600–900; для остальных ярких заливок отдельно проверять контраст.

При генерации иллюстраций указывать выбранные HEX и роли. Пример цветового блока: «Фон #B9EFFF, основной объект #355CFF, теневые плоскости #2039B4, небольшой акцент #FFD43B, блики #FFFFFF. Плоские непрозрачные заливки, без градиентов и фактуры». HEX в запросе задают целевую палитру; точность результата генерации проверяется отдельно.

Соблюдать DESIGN_STYLE.md: размер 700 × 525 px, полностью заполненный фон, прямые внешние углы, простые геометрические формы, объём через отдельные цветные плоскости.

## Файлы

- colors.json — единый набор значений и сочетаний.
- colors.css — переменные для подключения и совместимые названия основных цветов проекта.

Палитра подключена к приложению напрямую из `design-system/colors.css`. Интерфейсные состояния и основные компоненты используют семантические переменные; растровые иллюстрации меняются отдельно только по конкретному заданию.
