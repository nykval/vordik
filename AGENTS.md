# Требования к изображениям проекта

Для всех следующих изображений в этом проекте:

- Размер строго 700 × 525 px.
- При работе с исходным изображением сохранять его композицию и основные цвета, меняя содержание под текущую задачу.
- Фон должен быть сплошным и заполнять весь холст.
- У самого изображения и у внешней карточки или рамки не должно быть скруглённых углов.
- Цвета новых иллюстраций брать из `design-system/COLORS.md` — проектной копии предоставленного пользователем файла `/Users/zeliboba/Desktop/вордик дизайны/COLORS.md`. Перед созданием выбирать точные HEX для фона, основных плоскостей и акцента; не подменять их приблизительными оттенками, градиентами или случайными цветами. Если пользователь задаёт конкретные другие цвета или просит сохранить основные цвета исходного изображения, его задание имеет приоритет.

При создании следующих иллюстраций опираться на предоставленные пользователем референсы и описание их визуального языка в `DESIGN_STYLE.md`. Конкретное новое задание пользователя имеет приоритет над общими стилистическими наблюдениями.

# Тематические подборки словаря

Для работы с темами словаря используй только 20 названий из `THEMES.md`. Тема необязательна: оставляй ячейку пустой, если значение слова не подходит ни к одной подборке.
